# Bhasha Bridge — Flutter Mobile & Desktop Application

A cross-platform Flutter application for **Bhasha Bridge** bringing vernacular voice-first AI procurement and dynamic UPI 2.0 escrow lock directly to MSME smartphones and tablets across Karnataka.

---

## 📱 Features Included

1. **Bhashini Indic Speech ASR & Voice Assistant**:
   - Tap-to-speak audio capture for Kannada (ಕನ್ನಡ), English, and Kanglish queries.
2. **Dynamic UPI 2.0 Escrow Lock**:
   - In-app scannable QR code generation.
   - **1-Click Launch**: Direct intent launch into PhonePe, Google Pay, BHIM, and Paytm.
3. **Karnataka 31-Districts Supplier Discovery**:
   - Search Peenya CNC Toolings, Mysuru Silk Weavers, Belagavi Heavy Foundry, and Davangere Cotton Mills.

---

## 🚀 How to Run the Flutter App

```bash
# 1. Navigate to the flutter directory
cd bhasha_bridge_flutter

# 2. Fetch packages
flutter pub get

# 3. Launch on connected Android/iOS device or Chrome
flutter run -d chrome
```
